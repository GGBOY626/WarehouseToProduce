# 可选区分批次

同一产品、物料编码和原物料批次（batch）下，实际外盒仍有不同批次时，在流转产品明细填写“区分批次”。最多 100 字符，可留空，不创建重复产品，也不从备注自动推断。

例如编码 BOX-01、batch A001：

| 区分批次 | 箱规 | 箱数 | 总数量 |
| --- | --- | --- | --- |
| 印刷批次甲 | 1000 个/箱 | 3 | 3000 |
| 印刷批次乙 | 1800 个/箱 | 5 | 9000 |

两行在首页、历史记录、记录选择弹窗、流转详情和 PDF 总计表中分别显示和统计。整单及方向总计仍为 8 箱、12000 个；不会把两行物料统计错误合并为一个批次。相同区分批次的多种装箱规格仍合并数量，并保留规格明细。

## 登记和历史修正

1. 选择原有外盒产品，填写原物料批次、区分批次和数量。
2. 点击“添加同物料规格 / 批次”，同物料及区分批次会带入；将新行的区分批次改为另一批次，填写该批数量。
3. 不需要区分的普通产品留空即可；空白会规范化为 NULL。
4. 已有记录可编辑产品明细补填或拆为多行，手动核对各行数量总和。不会自动解析旧备注或重分配历史数量。
5. 切换产品会清空原区分批次；“复制为新单”与原物料批次一样清空，避免沿用错误批次。编辑原记录和添加同物料规格保留。

## 数据和接口

Flyway V14 仅给 `movement_item` 新增 `sub_batch VARCHAR(100) NULL`，不更新已有记录。

流转新增/编辑 `items[].subBatch` 可选，读取、列表物料和物料汇总返回 `subBatch`。按物料编码、原 batch、区分批次及基础单位分组，箱数、尾箱、散装和人工数量口径不变。编辑时带原 item id 而省略字段会保留原值；传空字符串可显式清空。历史没有区分批次的记录仍归入未填写组，与已填写组分开。

搜索支持区分批次，保留原来的按整张流转单搜索语义。生产任务匹配和整体备料进度仍按任务所需产品计算，不把区分批次误认为新产品。

## 验证

- 同编码、同 batch，甲 3000 个、乙 9000 个：物料统计两行，PDF 两组。
- 再登记甲 1800 个：甲合计 4800，乙仍 9000；甲保留两个规格。
- 未填写和仅空白字符为同一组，不与甲乙合并。
- 退料、尾箱、散装、编辑和作废仍按已有数量规则计算。
- 原记录补填后可读取并搜索；带原 item id 省略值不丢失，清空后回到未填写组。
- Java 21：`cd backend` 后 `mvn test`；前端 `npm test` 和 `npm run build`。
