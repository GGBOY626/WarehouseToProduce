# 前端 UI/UX 优化验收

## 范围

保留深蓝主色、白色卡片和浅灰背景，复用 Vue、Vue Router 和原有组件；未新增依赖，未修改后端、数据库或数量/进度/损耗计算公式。

- 首页：今日有效出库、入库/回仓单数来自分页接口的 `totalElements`；进行中和需关注任务来自任务接口。接口失败显示未获取状态，不用零或模拟值替代。物料数量仍按原接口的物料、批次和单位分别展示。
- 流转查询：日期预设、方向、搜索保持原行为；指定日期收进更多筛选，范围统计可折叠，保留多单选择和明细跳转。记录表照片移到列表下方。
- 任务：需关注任务稳定排序优先；概览和列表共用关注规则（缺料、数量待确认、配置或回仓数量待核对）。计算值直接使用接口；明细和批次独立折叠。
- 产品：卡片主体进入原编辑器，启停及删除放入菜单，保留确认；批次可折叠，箱规和业务字段保留。补齐加载、失败和操作成功反馈。
- 导航：顶部三个常用入口；更多菜单集中 PDF、人员管理和登录/退出，避免与表单固定保存栏冲突。

## 验证方式与结果

使用 agent-browser 连接本地前端，后端运行在隔离 H2 内存库；通过真实接口创建验收产品、任务及流转单，不连接生产数据库。

- 前端构建：`npm --prefix frontend run build` 通过。
- 单元测试：`npm --prefix frontend test`，19 项通过。新增关注规则、稳定排序及不修改计算数据的检查。
- 360、390、430、1280 像素：首页、产品、任务列表和详情无横向溢出；实际查看截图并修正了产品菜单符号宽度。
- 首页单数与测试数据一致；今天、昨天、本周、两周、指定一天、自定义起始日期、方向与无结果搜索均检查。
- 汇总项选择多张流转单、跳转记录详情正常。
- 产品通过界面新增、修改；启停及删除通过界面事件调用真实接口，检查确认文案及结果；取消确认不执行修改。
- 任务明细默认收起，展开物料详情后可独立展开批次；保留查看流转。
- 从概览进入需关注任务，滚动至 900px 后进入详情再返回，筛选与滚动位置均恢复。
- PDF 接口实际返回 PDF 内容；人员管理菜单入口可用。

本次未对生产环境执行部署或数据修改。开发配置和用户原有未提交文件不包含在提交中。
